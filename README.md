# Cerc – Probleme rezolvate în C++

Acest repository conține o colecție de probleme de programare rezolvate în C++, preluate de pe platforma PBInfo.

## Structura

- `Gata/` – probleme rezolvate și finalizate

## Tematici abordate

- Vectori și tablouri bidimensionale
- Șiruri de caractere
- Recursivitate
- Backtracking
- Algoritmi de parcurgere
- Probleme de algoritmică

## Limbaj de programare

- C++

## Scop

Repository-ul este creat pentru a păstra, organiza și urmări progresul soluțiilor mele la problemele de programare.
